# SEC-02 dependency security audit

Date: 2026-07-25

## Upgrade

- Go baseline: `1.25.0` → `1.26.5`
- `github.com/go-git/go-git/v5`: `v5.5.2` → `v5.19.1`
- `github.com/go-git/go-billy/v5`: `v5.4.0` → `v5.9.1`
- Transport-related transitive modules were resolved together by `go mod tidy`.

Go 1.26.5 is required because a scan with the previously installed Go 1.26.1 toolchain found
reachable standard-library vulnerabilities fixed between Go 1.26.2 and Go 1.26.5.

## Security gates

The default cgo-free source scan passes:

```text
$ GOTOOLCHAIN=go1.26.5 CGO_ENABLED=0 GOFLAGS=-mod=mod \
    go run golang.org/x/vuln/cmd/govulncheck@v1.6.0 ./...
No vulnerabilities found.
Your code is affected by 0 vulnerabilities.
```

CI now runs that scan on every push and pull request. Pull requests additionally run GitHub's
dependency review action at `low` severity or higher, so newly introduced vulnerable modules are
rejected even when their vulnerable symbols are not reachable from the default build.

## Transport and compatibility verification

The following focused checks pass with Go 1.26.5:

```bash
CGO_ENABLED=0 GOFLAGS=-mod=mod go test -count=1 \
  -run 'TestLoad(RemoteRepositories|LocalRepository|FileRepository|SivaRepository)|TestRepositoryCloneOptions(HTTPSCredentials|SSHIdentity)' \
  ./cmd/hercules

CGO_ENABLED=0 GOFLAGS=-mod=mod go test -count=1 \
  -run 'TestBlobCache(GetBlobIgnoreMissing|GetBlobGitModulesErrors)' \
  ./internal/plumbing

CGO_ENABLED=1 GOFLAGS=-mod=mod go test -tags purego -count=1 \
  -run TestPluginCompatibilitySmoke ./test/plugin_smoke
```

These checks cover hermetic remote HTTPS and SSH clone dispatch through an in-process go-git
transport, HTTPS credential redaction, SSH private key loading, real local-path and `file://`
repositories, the checked-in Siva fixture, missing submodule behavior, and plugin
loading/execution.

The full default suite was also run:

```bash
GOTOOLCHAIN=go1.26.5 CGO_ENABLED=0 GOFLAGS=-mod=mod go test -count=1 ./...
```

It has no dependency-upgrade regressions. It still reports the same pre-existing `internal/core`
and `internal/toposort` failures recorded in the
[BASE-01 baseline](2026-07-25-base-01.md); all other packages pass.

The following checks pass:

```bash
GOTOOLCHAIN=go1.26.5 CGO_ENABLED=0 GOFLAGS=-mod=mod go vet ./...
GOTOOLCHAIN=go1.26.5 CGO_ENABLED=0 GOFLAGS=-mod=mod \
  golangci-lint run --config ./.golangci.toml --timeout 5m \
  --modules-download-mode=mod --new
```
