# Visual regression goldens

These PNGs are generated by the in-repository Go renderer from the small
fixtures in `internal/render/testdata/example_data/` and
`test/visual/testdata/`. Both the renderer and fixtures are part of this
Apache-2.0 repository; the images do not depend on the retired Python package
or an external repository. The developer fixture is hand-authored and uses
fictional names.

The pull-request gate covers four rendering families:

- `burndown_project.png`: stacked time-area chart
- `devs.png`: annotated developer time-area chart
- `file_coupling_heatmap.png`: matrix heatmap
- `top_file_coupling_pairs.png`: ranked bar chart

The gate requires the exact artifact set and deterministic PNG bytes. Refresh
the set only after reviewing the rendered differences:

```bash
just update-visual-goldens
just test-visual-gate
```
