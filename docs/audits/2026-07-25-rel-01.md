# REL-01 CLI failure semantics verification

Date: 2026-07-25  
Status: completed

## Result contract

Rendering now returns a `render.Result` containing:

- one `ModeResult` per requested mode, with either a hard `Err`, a typed optional-data `Warning`,
  or neither on success;
- a run-level `OutputError` for failures writing combined output such as JSON;
- `Result.Err()`, which is `nil` for success and warning-only success and joins every hard mode
  and output failure otherwise;
- `Result.HasWarnings()`, which exposes warning-only outcomes without parsing diagnostic text.

The renderer continues independent modes after either a warning or a hard failure. Diagnostics are
written to stderr. `labours` uses Cobra `RunE` and returns `Result.Err()`, so its process status is
zero for success and warning-only success and nonzero for hard failures.

Only errors satisfying `errors.Is(err, readers.ErrAnalysisMissing)` are warnings. Legacy YAML and
protobuf reader paths now emit that sentinel for absent optional analyses and preserve
`ErrAnalysisMalformed` for invalid protobuf payloads. Unrelated errors containing words such as
`no`, `not found`, or `missing` remain hard failures.

`hercules report` records warnings and hard mode failures in `index.html` and `manifest.json`, then
returns an error after atomically publishing a non-strict partial report. `--strict` aborts before
publication, leaving any previously complete report intact.

## Combine contract

`hercules combine` now sends every input, including a single input, through protobuf parsing,
analysis deserialization, and serialization. It:

- returns nonzero for malformed inputs, even if independent valid inputs produced partial output;
- fails before writing output when no valid analysis was merged or `--only` is unavailable;
- propagates output writer failures, including a broken stdout pipe;
- merges repository metadata only when at least one selected analysis from that input merged
  successfully;
- keeps diagnostics on stderr and writes only protobuf bytes to stdout.
